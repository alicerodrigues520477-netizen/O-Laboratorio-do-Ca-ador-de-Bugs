Gaveta 04 — Diário de Campo

28 set 2026 #QA

Como escrever um bug report que o time realmente usa

Aprendi que um bom report tem passos claros pra reproduzir, comportamento esperado x encontrado, severidade e evidência (print ou log) — sem isso, o dev perde tempo só tentando entender o problema.

22 set 2026 #TestesManuais

Testando valores-limite (boundary testing)

Pratiquei testar os extremos de um campo numérico — mínimo, máximo, um valor abaixo e um acima. É nessas bordas que a maioria dos bugs de validação aparece.

16 set 2026 #QA

Priorizando bugs: impacto x frequência

Estudei uma matriz simples pra decidir o que corrigir primeiro: bugs de alto impacto e alta frequência sobem pro topo da fila, os de baixo impacto e baixa frequência esperam.

08 set 2026 #TestesManuais

Testes manuais vs. automatizados

Entendi melhor quando vale a pena escrever um teste automatizado e quando um teste exploratório manual encontra mais problemas reais, principalmente em telas novas.

03 set 2026 #Acessibilidade

Fundamentos de acessibilidade (WCAG)

Estudei os princípios POUR e comecei a testar navegação só com teclado — descobri três armadilhas de foco que eu nunca tinha percebido antes.

28 ago 2026 #QA

Introdução a testes de API
